# Employee Attrition Prediction System

**Final Year Machine Learning Project**

A complete end-to-end machine learning system that predicts whether an employee is likely to leave the organization and explains *why* using SHAP (Explainable AI). The solution is also deployed as an interactive Streamlit dashboard for practical HR use.

## Project Overview

Employee attrition is costly for organizations. This project builds a predictive model using the IBM HR Analytics dataset to:

- Estimate the probability that an employee will resign
- Classify risk level (Low / Medium / High)
- Explain the key drivers of the prediction using SHAP
- Provide an easy-to-use web interface for HR teams

---

## Dataset

- **Source**: IBM HR Analytics Employee Attrition & Performance (Kaggle)
- **Size**: 1,470 employees, 35 features
- **Target**: Attrition (Yes/No) — approximately 16% positive class
- **Key features**: Age, Monthly Income, OverTime, Job Satisfaction, Environment Satisfaction, Department, Years at Company, etc.
